# v1.23.2 - Stagehand 4.4.0 Ends the Windows Browser-Close Failures

Date: 2026-11-19

## What changed

- `@browserbasehq/stagehand` moves from `^4.2.1` to `^4.4.0`.
- With 4.2.1, closing a browser the harness launched on Windows went straight to `taskkill`: a
  non-forced call headless Chrome ignores, a 3 second wait, a forced kill, then one attempt to delete
  the temporary Chrome profile with no retry. Chrome's helper processes were sometimes still writing
  cache files, so `browser.close()` rejected with
  `ENOTEMPTY: directory not empty, rmdir '...\\stagehand-chrome-...\\Default\\GPUCache'`. The harness UI
  tests (`npm run vibe:test-ui`) then failed in teardown although every assertion had passed, and the
  run sometimes did not return.
- 4.4.0 asks Chrome to exit over DevTools (`Browser.close`) before it touches the process, which is
  the first step proposed in browserbase/stagehand#3166. Chrome leaves on its own, the profile is
  deleted after it has gone, and the 3 second wait disappears.
- The harness wrapper (`.vibe/harness/scripts/lib/stagehand-browser.mjs`) is unchanged. Stagehand
  still deletes the profile once without a retry; no failure showed in the runs below, so the wrapper
  does not take the profile over.

## Downstream impact

- `dependencies` and `devDependencies` are project-owned in `package.json`, so a sync does not change
  the installed Stagehand. Update it in the project:
  `npm install -D @browserbasehq/stagehand@^4.4.0`.
- Stagehand 4.4.0 requires Chrome 137 or later.
- No harness source, migration, schema or protocol change.

## Verification

- Same loop on the same Windows machine, opening a page and closing the browser through the harness
  wrapper: 4.2.1, 40 cycles, 3 failures (`ENOTEMPTY` in `GPUCache`, `DawnGraphiteCache`, `WebStorage`),
  close median 4.2 s; 4.4.0, 100 cycles, 0 failures, close median 0.65 s.
- `npm run vibe:test-ui`: 3 failures in 10 runs on 4.2.1 (about 25 s a run); 20 of 20 passed on 4.4.0
  (about 8 s a run).
- Full forced release verification, nine groups: legacy 651 tests, 650 pass, 1 skip, 0 fail; Astra 643
  tests, 641 pass, 2 skips, 0 fail. Build, tracked wrapper, shard, sprint-mode, sync and config audits
  passed.
