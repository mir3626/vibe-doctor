# v1.15.2 - Pro Tests Follow Patch Impact

Date: 2026-09-09

Ordinary harness patches now run only the affected test groups through
`npm test`, `vibe:self-test` and `vibe:verify`. The Pro group uses an explicit
dependency list: unrelated dashboard, interview and other shared helper edits
do not start its temporary Git/worktree tests or invalidate its passing receipt.
Pro runtime, schemas, protocol documents, tests and actual shared dependencies
still select Pro verification.

Push/PR CI compares the prior push or PR base using full checkout history, so
committed changes are tested even in a clean checkout. Unknown harness impact,
invalid comparison bases and verification/dependency/CI configuration changes
still select all groups. `vibe:self-test:all` and `vibe:verify:release` retain
explicit full forced verification. This selection policy applies to all models.

Run a dry-run before syncing `v1.15.2`. Preserve project scripts and local
customizations. Projects with a custom CI workflow should pass a comparison
base to changed-group tests, or explicitly request the full test command;
otherwise a clean checkout has no uncommitted changes to select. Pro protocol
and product runtime behavior are unchanged; no product migration is required.
