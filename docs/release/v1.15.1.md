# v1.15.1 - Windows CI Preload Correction

Date: 2026-09-07

The focused Windows CI job now loads the same hidden-child-process preload as
the standard harness verifier. Its two preload-contract tests failed in v1.15.0
because the direct CI command omitted that setup; the Linux legacy and Astra
jobs passed, as did local full forced verification for both profiles.

This patch changes CI setup, release metadata and documentation. Runtime code,
tests and the Astra/lower-model compatibility boundary are unchanged. The
published v1.15.0 tag remains immutable. No product migration is required.

Sync the correction using `npm run vibe:sync -- --ref v1.15.1`, reviewing the
dry-run first and preserving project-owned CI customizations.
