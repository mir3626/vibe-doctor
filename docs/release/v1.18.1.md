# v1.18.1 - Template Hygiene Hotfix

Date: 2026-10-13

v1.18.0 added the downstream queue document at the top of `docs/plans/`. The template hygiene test
allows only `.gitkeep` and `sprint-roadmap.md` there, so the CI `verify` and `astra` jobs failed. The
local release validation passed because the document was not yet tracked when it ran, and the test
checks tracked files.

## What changed

- The queue document moves to `docs/plans/downstream/vibe-office-queue.md`, beside the existing
  `docs/plans/github-pro-roundtrip/` design documents. `harness-gaps.md` and the v1.18.0 note point to
  the new path.
- No runtime, schema, migration, or protocol change. Version metadata moves to 1.18.1.

## Downstream impact

- None beyond v1.18.0: `docs/plans/` is not synced, and the two text references live in synced docs.

## Verification

Release validation (2026-10-13, Windows 11) ran after staging every release file, so template-only
checks saw the shipping set: forced `vibe:verify:release` passed all nine groups with 624 tests (623 passed,
one conditional platform skip, zero failures), template hygiene included.
